# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。

## 候选分组如何判定

总分保留未舍入值，界面显示四舍五入后的整数；建议、曲线断层线、名次和梯队看板共用同一份分组结果：

- 相邻两方案未舍入差距 ≥ 5 分 → 明显断层，切为不同梯队；
- 新成员与当前梯队最佳的未舍入差距 ≥ 5 分 → 也单独成组。

因此「逐项接近」不会把首尾并组：0/4/8 每环只差 4 分，但 8 距梯队最佳 0 达 8 分，分成 [0,4]、[8]；0/4.9/5.1 中 4.9 与 5.1 只差 0.2，但 5.1 距最佳 5.1 分，仍切开。差距不足 1 分视为同一显示精度、名次并列。只有榜首梯队唯一时才点名推荐；榜首梯队多人时只说难以区分，不会同时出现「唯一推荐」和「无法区分」。分组只取决于未舍入分数，改名或调整录入顺序不改变结论。
