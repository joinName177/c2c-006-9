# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。

## 候选分组与建议

名次、分组与建议使用同一判定依据：各方案 1/5/10 年指数的**未舍入**加权总分（整数总分仅为显示取整）。按（未舍入总分, 选项 id）排序后，以「组内最佳者」为参照贪心分组——与组首差距小于 5 分才并入该组，否则开启新梯队。因此：

- 第一梯队即「与最佳方案相差不到 5 分」的全部方案，推荐文字会逐一列出，不会遗漏同样接近者；
- 任意组内首尾差距必然小于 5 分，逐项接近（如 0/4/8/12）不会把明显不同的首尾连锁并入同组；
- 第一梯队唯一时才有明确推荐方向，否则建议补充信息，二者不会同时出现；
- 分组只依赖分数与选项 id，与名称、录入顺序无关，相同输入结果必然相同。
